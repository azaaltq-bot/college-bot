# Помощник студента ЧТЖТ (Telegram-бот)

Бот подсказывает студенту, какая у него сейчас пара и сколько осталось до конца половины или всей пары. Расписание и звонки администратор заполняет прямо в боте.

## Файлы

- `bot.py` — сам бот: кнопки, регистрация, админ-команды
- `logic.py` — расчёт текущей пары, числитель/знаменатель (без Telegram)
- `database.py` — работа с базой SQLite
- `ai_parser.py` — распознавание расписания по фото через DeepSeek
- `config.py` — настройки (ключи берутся из переменных окружения, в коде их нет)
- `railway.json`, `Procfile` — настройки запуска на Railway
- `test_logic.py` — проверка логики без запуска бота

## Запуск на Railway (всё делается с телефона в браузере)

**1. Загрузи код на GitHub**
1. Распакуй архив на телефоне (в «Файлах» нажми на архив → «Извлечь»).
2. На github.com нажми **+ → New repository**. Название, например, `college-bot`, выбери **Private** (приватный), нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и выбери все файлы из папки `college_bot` (не сам архив). Нажми **Commit changes**.

**2. Подключи Railway**
1. На railway.com войди через GitHub.
2. **New Project → Deploy from GitHub repo** → выбери `college-bot`.

**3. Добавь ключи** (вкладка сервиса **Variables → New Variable**):
- `BOT_TOKEN` — токен бота
- `DEEPSEEK_API_KEY` — ключ DeepSeek
- `DB_PATH` — `/data/college_bot.db`

`ADMIN_IDS` можно не задавать: по умолчанию админ — 1431708118. Чтобы добавить ещё админов, задай `ADMIN_IDS` через запятую.

**4. Добавь Volume (обязательно!)**
Без него база (расписание и пользователи) стирается при каждом перезапуске.
В проекте нажми **+ / New → Volume**, подключи его к сервису бота и укажи путь (Mount path) `/data`.

**5. Проверь**
Во вкладке **Deployments → View logs** должна появиться строка «Бот запущен». Напиши боту `/start`, затем `/admin`.

**Важно:**
- Не запускай бота одновременно на Railway и на компьютере с тем же токеном: Telegram будет выдавать ошибку конфликта.
- Когда перевыпустишь токен или ключ, просто поменяй значение в Variables. Код трогать не нужно.
- Ключи никогда не пиши в файлы на GitHub.
- Обновить код: загрузи изменённый файл на GitHub, Railway сам перезапустит бота.

## Загрузка расписания по фото (ИИ)

1. Отправь боту фото или скриншот расписания. Лучше файлом (без сжатия) и одной группы, а не весь стенд.
2. Если на картинке не написано название группы, подпиши фото: `ТС 9-26-3`.
3. Бот покажет, что распознал. Проверь и нажми:
   - **Сохранить (заменить)** — старое расписание этих групп удалится, запишется новое;
   - **Добавить** — новые пары добавятся к уже существующим;
   - **Отмена** — ничего не запишется.

Это работает только для админов. Остальные пользователи фото загрузить не могут.

DeepSeek API платный (но очень дешёвый), на балансе platform.deepseek.com должно быть немного денег. Если бот пишет про ошибку модели, DeepSeek мог переименовать экспериментальную модель — задай новое название в переменной `DEEPSEEK_MODEL`.

## Заполнение расписания вручную

Звонки (номер пары, начало и конец 1-й половины, начало и конец 2-й):
```
/add_bell 1 08:30 09:15 09:20 10:05
/add_bell 2 10:15 11:00 11:05 11:50
```

Пары. Можно несколько строк в одном сообщении:
```
/add_lesson ТС 9-26-3; пн; 1; Математика; 214; Иванова И.И.; каждая
ТС 9-26-3; пн; 2; Физика; 305; -; числитель
ТС 9-26-3; пн; 2; Информатика; 110; -; знаменатель
```
Формат: `группа; день; пара; предмет; кабинет; преподаватель; неделя`.
Кабинет, преподавателя и неделю можно не писать (неделя по умолчанию — каждая).

Проверить: `/schedule ТС 9-26-3`. Удалить ошибочную запись: `/del_lesson 5`.

Если у пары нет перерыва посередине, укажи конец первой половины равным началу второй: `/add_bell 1 08:30 09:15 09:15 10:00`.

## Числитель и знаменатель

В `config.py` указана дата начала семестра (`SEMESTER_START`). Неделя с этой датой — числитель, следующая — знаменатель и т. д. Во втором семестре поменяй дату. Текущую неделю показывает команда `/week`.

## Проверка логики

```
python test_logic.py
```
Скрипт проверяет ответы бота в разное время: до пар, в первой половине, на перемене, во второй половине, в «окно» и после пар. Удобно показать на защите.

## Идеи для развития

- Замены в расписании на конкретную дату
- Отдельные звонки для субботы и сокращённых дней
- Уведомление за 5 минут до начала пары
- Веб-админка вместо команд
