# Помощник студента ЧТЖТ (Telegram-бот)

## Файлы
- `bot.py` — кнопки, регистрация, настройки, админ-панель, «живой» таймер
- `logic.py` — курс по группе, текущая пара, оформление, проверка ответа ИИ (без Telegram)
- `database.py` — SQLite (старая база обновится сама)
- `config.py` — настройки и переменные окружения
- `ai_parser.py` — распознавание расписания по фото
- `test_logic.py` — проверка логики: `python test_logic.py`

## Что умеет
- **📍 Текущая пара** — сообщение с таймером до конца половины и пары (чч:мм:сс, время Читы). Повторное нажатие удаляет старое сообщение и присылает новое.
- **📅 Расписание на сегодня** — пары со статусами ✅ / ▶️ / ⏳, окна и обед.
- **⚙️ Настройки** — ФИО, специальность, группа, курс, сегодняшняя дата, неделя. Внутри: изменить данные, звонки и обеды курса, объяснение зелёного и синего расписания (`/week`).
- **🛠 Админ-панель** (только админ) — выбираешь курс 1–4, дальше отдельно: расписание (фото / текст), звонки, обеды.

## Курс определяется сам
В названии группы `ТС 9-26-3` число **26** — год поступления. Учебный год начинается 1 сентября:
в 2026/27 это 1 курс, в 2027/28 — 2-й, и т. д. (`25` сейчас = 2 курс). Менять ничего не нужно.

## Специальность
Бот берёт буквы группы (`ТС`) и ищет название, которое ты задашь один раз:
```
/set_specialty ТС Полное название специальности
```

## Если Telegram ограничивает частые правки
В `config.py` (или переменной Railway) поставь `LIVE_INTERVAL=2` — таймер будет обновляться раз в 2 секунды.

## Запуск
```
pip install -r requirements.txt
python bot.py
```
Переменные: `BOT_TOKEN`, `ANTHROPIC_API_KEY`, `DB_PATH` (на Railway — путь внутри Volume), `ADMIN_IDS`.


## Коды групп и автоисправление

Список букв групп (ТС, ГНХ, ИТД …) лежит в `specialties.py` (`PREFIXES`) — допиши туда недостающие.
Админ может добавить код и без правки файла: `/set_specialty КОД Название специальности`.

Если студент ошибся в **буквах** («Тэс 9-26-1,2»), бот сам исправит на «ТС 9-26-1,2».
Цифры не меняются. При регистрации бот показывает шаблон: **ТС 9-26-3,4**.
Официальные специальности ЧТЖТ (по irgups.ru) показываются в админ-панели → «Специальности».


## ИИ: Nemotron 3 Ultra

Переменные Railway:

| Переменная | Что это |
|---|---|
| `AI_API_KEY` | ключ бесплатного ИИ |
| `AI_BASE_URL` | адрес API сервиса. Если ключ начинается с `nvapi-` (NVIDIA) или `sk-or-` (OpenRouter), адрес определяется сам, иначе его нужно указать |
| `AI_MODEL` | название модели в каталоге сервиса (по умолчанию `nvidia/nemotron-3-ultra-550b-a55b`) |
| `AI_VISION_MODEL` | необязательно: модель, которая видит картинки. Без неё фото не принимаются |

Админ-панель → курс → **Расписание** / **Звонки** → «🤖 ИИ разберёт…»: присылаешь текст в любом виде,
ИИ приводит его к формату, бот показывает результат, ты подтверждаешь. Для звонков ИИ понимает
и обе половины пары, и просто «1 пара 8:30–10:05» (пара делится пополам), и обед.

## Зелёное и синее расписание

Вместо «числитель/знаменатель»: 🟢 зелёное расписание (первая неделя) и 🔵 синее (вторая).
При вводе вручную пиши `зелёная` / `синяя` (старые слова тоже работают).
